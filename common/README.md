# common/users.js（兄弟で1台を使う「使う人」の切りかえ）

**このサイト（study-game）のアプリには、すべてこれを入れる。新しく作るアプリにも必ず入れる。**

## 入れ方（3か所）
1. `<head>` の `<meta charset>` のすぐ下（ほかのどの `<script>` よりも前）に
   ```html
   <script src="../common/users.js?v=1" data-app="フォルダ名"></script>
   ```
   トップ（暗記クエスト）だけ `src="common/users.js?v=1"`。
2. 設定画面のいちばん上あたりに `<div data-users-card></div>`（JS で描きなおす画面なら、そのテンプレートの先頭に入れる）。
   設定画面がないアプリは、メニューや「その他」の画面など、いつでも開ける場所に入れる。
3. 見出し（header）の右側、使い方ボタンの左などに `<button data-users-tag hidden></button>`（2人以上のときだけ名前が出る。押すと切りかえの画面）。

アプリ側のコードは変えなくてよい（localStorage と IndexedDB の保存名を、共通部品が人ごとに分ける）。
入れたら、アプリの版（VER・sw.js・version.json）を1つ上げる。

## しくみ・注意
- 1人目は今までの保存名のまま。2人目からは localStorage のキーと IndexedDB の名前のうしろに `__u…` がつく。名簿は `sgusers_<data-app>`。
- 切りかえ・ふやす・消すと、ページを読みなおす。消せるのは2人目から（1人目の記録は各アプリの「記録を消す」で）。
- `localStorage.key(i)` で全部のキーを回して消す「掃除」のコードを書くときは、`__u` で終わるキー（ほかの人の記録）を消さないこと。
- 語彙1300（goi）と英検の各級（eiken-*）は、先に入れた「アプリの中に書いた版」（設定に「使う人」カード）。共通部品とは別だが、同じ考え方。
- 計画マップ（plan）と Essence（missmap）は、それぞれ独自の「使う人」がある。
