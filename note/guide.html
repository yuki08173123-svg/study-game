ホーム画面に入れる

アプリストアからは入れません。上のQRコードを読むか、リンクを開いてから、次の手順でホーム画面に置いてください。 ふつうのアプリと同じように、アイコンから開けるようになります。

  2. 画面の下にある共有ボタン をタップ
  3. メニューを下にたどって「ホーム画面に追加」
  4. 右上の「追加」をタップ

Android

Chrome で開く
  1. Chrome で上のリンクを開く
  2. 右上の をタップ
  3. 「ホーム画面に追加」を選ぶ
  4. 「追加」をタップ
02

やることは三つ

書く

右下の丸いボタンから、学んだこと・気づいたことを書きます。 一行目が見出しになるので、要点を短く書いておくと、あとで探しやすくなります。

写真も一件につき八枚まで付けられます。板書やスライドを撮っておくだけでもかまいません。

写真は1枚ずつ「表」と「裏」を切り替えられます（写真の左下のボタン）。 問題の写真を表、解いた答えの写真を裏にしておくと、そのままカードとして使えます。

本文は1行目が表、2行目からが裏です。振り返りでは1行目だけが出ます。

分ける

フォルダは自分で作れます。教科でも、本と動画でも、分け方は自由です。

フォルダの中に、さらにフォルダを作れます（何段でも）。 「語彙 → 語彙力アップ① → Unit 1」のように、範囲ごとに分けておけます。

あとから上位フォルダを作って、既存のフォルダをその中に入れることもできます。 ホームの「整理」→ 行の名前をタップ →「場所」から変更してください。

先に書きためてあとから整理してもかまいません。メモは後で移せますし、フォルダを消しても中のメモは未分類に残ります。

思い出す

まん中の「振り返り」を開いてはじめるを押すと、しばらく開いていないメモが数件えらばれ、一行目だけが出ます。 続きを頭の中で言ってから「続きを表示」を押してください。

範囲を押すと、単元だけ・フォルダだけ・全部を切り替えられます。 件数は1件きざみで調整でき、「全部」も選べます。 試験前に一つの単元を詰めたいときと、全範囲を通したいときで使い分けてください。

一覧のカード右上の★を押しておくと、範囲で「重要マークだけ」を選べます。 直前期に、これだけは落とせないものを毎日まわすのに使えます。

振り返り画面の「メモ」「未確認」「2週間以上」の数字も押せます。 押すと、そのメモだけがすぐ出題されます。

読み返すより、閉じて思い出すほうが記憶に残ります。これがこのアプリの本体です。 ただ眺めたいときはシャッフルを押すと、その範囲をばらばらの順に見ていけます。

03

知っておくこと

保存される場所
書いたメモと写真は自分の端末の中だけに保存されます。どこにも送信されません。先生にも他の人にも見えません。
消えるとき
ブラウザの履歴やサイトデータを消すと、メモも一緒に消えます。端末を変えるときも引き継がれません。 大切なメモは書き出しを
未確認をすぐ見る
ホームの「未確認」の数字を押すと、まだ一度も確認していないメモだけが並びます。 その画面の「この◯件を振り返る」を押せば、そのまま出題が始まります。 フォルダの中でも同じボタンが出るので、範囲を決めて振り返れます。
あとで整理する
一覧の右上「選択」から、複数のメモをまとめてフォルダへ移動できます。 とりあえず未分類に書きためて、あとから仕分ける使い方ができます。
消しても戻せる
削除したメモはゴミ箱に入ります。設定 → ゴミ箱から「戻す」でいつでも復活できます。 「選択」からまとめて消すこともできます。
書き出し方
設定 → 書き出し → JSON（写真ごと・復元用）。出てきたファイルを保存しておけば、 新しい端末で「JSONから読み込む」を選ぶとそのまま元に戻せます。
通信
一度ホーム画面に入れれば、電波がなくても開けます。広告は出ません。料金もかかりません。
新しくする
機能が増えたときは、開いたときに知らせが出ます。出ないときは 設定 → 更新を確認。 メモは消えません。
