# 📜 古文単語350 ができました
**古文単語は、くり返した回数で決まります。**
重要古文単語350語を、1日50語 × 7日で1周。これを **8周（約2か月）** くり返して、ぜんぶ覚えきるアプリです。

**▼ ここから開く**
https://yuki08173123-svg.github.io/study-game/kobun/

## ⚠️ 最初にやること：ホーム画面に追加
> ホーム画面に追加していないと、しばらく開かない間に **記録が消えることがあります。**
> 2か月つづけるアプリなので、かならず最初にやってください。

### 📱 iPhone・iPad
1. 上のリンクを **Safari** で開く
2. 画面の下の **共有ボタン**（四角から矢印が出ている印）を押す
3. 少し下にスクロールして **「ホーム画面に追加」** を押す
4. 右上の **「追加」** を押す
5. これからは、ホーム画面にできた **アイコンから開く**
-# LINE や Instagram の中で開いた場合は、先に「Safari で開く」を押してください。

### 🤖 Android
**Chrome** で開く → 右上の ⋮ → **「ホーム画面に追加」**
-# 追加できると、アプリの上に出ている赤い帯が消えます。

## ✍️ 使い方：毎日「覚える → テスト」だけ
はじめて開くと **使い方（8枚）** が出ます。あとから見るときは、右上の **「？」** か、設定タブのいちばん上から。

その日にやる50語は、**「今日」の画面**に出ています。

1. **① 覚える時間**
　時間を自分で決めてスタート。のこり時間が画面のいちばん上に出ます
-# 覚え方は 単語カード／一覧（意味をかくせる）／1分解説（スライド＋音声）から選べます
2. **② テスト 50問**
　4択です。時間と正答率は自動で記録。まちがえた語は、その場でもう一度
3. **次の日は、リマインドテストから**
　まちがえた語が、翌日 → 3日後 → 1週間後 にもどってきます
-# 遅れても大丈夫です。次にやる日から続きが出ます。

## 📈 ためると見えてくるもの
- 覚える・解くたびに **XP** がたまり、**レベル** が上がります
- レベルが上がると、平安時代の位が上がります：**無位 → 初位 → … → 大臣 → 関白**
- 「今日」の画面の **8周の表** に、毎日の正答率がたまっていきます
-# XP のもらい方は、右上の「Lv.」を押すと見られます。

## 📤 テストが終わったら、勉強報告に貼る
結果画面の **「報告用にコピー」** を押すと、覚えた時間・正答率・テスト時間が1行にまとまります。
**そのまま勉強報告に貼ってください。**

## 💾 記録の保存について
記録は **自分のスマホの中だけ** に保存されます。
ときどき設定の **「控えを作る」** を押しておくと安心です。機種変更のときにも使えます。
