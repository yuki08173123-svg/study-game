### 1. 分ける
```
cd ~/study-game && python3 tools/eiken-review/split.py eiken-3
```
→ `eiken-3/data/review/src/` に w0.jsonl（単語200件ずつ）・i0.jsonl（熟語170件ずつ）ができる。
前に見直しをしていて `data/review/` に w*.jsonl・i*.jsonl が残っていたら、別のフォルダ（例 `review_前回/`）に移してから始める。

### 2. 見直し担当（サブエージェント）を、ファイルの数だけ同時に出す
1人に1ファイル。指示はこれだけでよい（担当名と級を入れかえる）：
> ~/study-game/tools/eiken-review/REVIEW.md を読んで、そのとおりに点検してください。
> 級のルール：~/study-game/eiken-3/data/INSTRUCTIONS.md
> 担当：~/study-game/eiken-3/data/review/src/w0.jsonl
> 出力：~/study-game/eiken-3/data/review/w0.jsonl
> 担当ファイルと words.js・idioms.js は書きかえないこと。

全員の報告を待つ。報告にある「直さなかったが気になった点」は自分で判断し、直すものは `data/review/wm.jsonl`（単語）・`im.jsonl`（熟語）に同じ形で書く。

### 3. 直しを入れる
```
python3 tools/eiken-review/apply.py eiken-3 --check   # まず検査だけ（問題 0 を確かめる）
python3 tools/eiken-review/apply.py eiken-3           # words.js・idioms.js に入れる
```
- もとの js は初回に `data/review/backup_*.js` に控えられる。直しはいつも控えから当てるので、何度やり直しても同じ結果になる。
- `data/` からの作り直し（assemble.py など）で js を作り直したときは、最後にもう一度 apply.py を実行して直しを当て直す。

### 4. 確かめる
- 過去問の正解がまだ全部入っているか（その級の data に cover.py などの照合があれば実行）。
- localhost でアプリを開き、単語数・熟語数・カード・テストが動くか（~/.claude/launch.json の確認用サーバーを使う）。

### 5. 音声を作り直す
```
python3 tools/eiken3-audio.py --only w & python3 tools/eiken3-audio.py --only i & wait
```
変わった項目だけ作り直される（最後に「作り直し N件」と出る）。

### 6. 公開
- バージョンを1つ上げる：index.html の `const VER`、sw.js の VER（例 `e3-v5`）、version.json の `v` と note。
- index.html の `words.js?v=N`・`idioms.js?v=N` も1つ上げる。
- `git add <フォルダ>` → コミット → `git push origin main main:gh-pages`（くわしくはメモリの manabi-quest-deploy）。
- `https://yuki08173123-svg.github.io/study-game/<フォルダ>/version.json` が新しい v になるまで待つ。

### 7. ユーザーへの報告
- 点検した件数・直した件数、種類別の内訳（訳・例文・訳文・覚え方 など）と代表的な例を、やさしい日本語で。
- 「AIによる確認で、人の目での確認ではない」ことも伝える。
- 生徒には「アプリを完全に終了して開き直すと新しい版になる」と案内。

## 前回（準1級）に多かったまちがい（見直し担当にも REVIEW.md で伝えてある）
1. 例文で、見出し語がテストの正解（m）とちがう意味で使われている（dissolve, reconcile, administer, confer, dubious など約15件）
2. 覚え方のでたらめな語源（paramount, redeem, testify, compile, fluid, quota など17件）
3. 4択でほかの語と区別できない訳、中心からずれた訳（pragmatic, aesthetic, publicity など12件）
4. 訳文の [ ] の位置ずれ、不自然な日本語
5. 高校生向けにふさわしくない派生語（erect → erection）
